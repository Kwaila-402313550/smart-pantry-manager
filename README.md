Smart pantry manager

 About the Project
Smart Pantry Manager is an Android application developed using Java in Android Studio. The app helps users manage the ingredients they have at home and find recipes based on the ingredients available in their pantry.

The main purpose of the application is to reduce food waste and help users make better use of the food they already have.

 Project Objectives
- Help users manage pantry ingredients.
- Allow users to add, view, edit and delete pantry items.
- Help users find recipes using available ingredients.
- Monitor ingredient expiry dates.
- Reduce household food waste.

 Features
- Add Ingredients: Add ingredients to the pantry.
- View Ingredients: Display saved pantry items.
- Edit Ingredients: Update existing pantry information.
- Delete Ingredients: Remove unwanted pantry items.
- Recipe Suggestions:Suggest recipes based on available ingredients.
- Expiry Date Checking:Help users identify ingredients approaching their expiry dates.
- Navigation: Move between different screens of the application.

Technologies Used
- Java – Application programming language.
- Android Studio – Development environment.
- XML – Designing the user interface.
- GitHub – Source code management and version control.

 How the Application Works
1. Open Smart Pantry Manager on an Android device or emulator.
2. Add ingredients to the pantry.
3. View, edit or delete ingredients as needed.
4. Open the recipe suggestions section.
5. Check which recipes match the available ingredients.
6. Check expiry dates to help manage food more effectively.

 Testing
The application should be tested to check that:
- Pantry items can be added successfully.
- Existing items can be viewed and edited.
- Items can be deleted.
- Recipe suggestions follow the application's ingredient-matching rules.
- Saved information remains available after closing and reopening the app, if persistence is implemented.
- Invalid or empty inputs are handled appropriately.

Challenges and Solutions
During development, possible challenges included:

- Pantry management: Ensuring that adding, editing and deleting items work correctly.

- Debugging: Testing the application and correcting errors in the Java code.
